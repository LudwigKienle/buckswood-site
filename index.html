Hermes, built in

Your AI agent can use every tool you can.

Buckswood runs a local MCP server and REST API. Connect Claude Code, Claude Desktop or Codex with one click in Settings, and the agent works on the same project you see, live.

  • Script, cast, storyboard, generation and continuity review
  • Long batches run as background jobs you can cancel
  • Every agent action is listed in Settings
